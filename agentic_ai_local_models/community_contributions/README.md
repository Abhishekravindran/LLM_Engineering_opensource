# Community Contributions
add your own
experiments here.

**To contribute:**
1. Fork this repo.
2. Create `community_contributions/<your-name>/your_notebook.ipynb`.
3. Keep it runnable on at least one of the two tracks (Colab or local PC) —
   say which one in a markdown cell at the top.
4. Open a Pull Request.

Ideas: a new tool for the Week 1 agent, a different local model
comparison, a new MCP server, or a mini-project combining two frameworks.
