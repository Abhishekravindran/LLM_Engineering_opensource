# Fine-tuning Local Frontier Models

This folder contains implementations and experiments related to fine-tuning local frontier language models.

## Topics Covered

- Local LLM fine-tuning workflows
- Dataset preparation
- Model training pipelines
- Parameter Efficient Fine-Tuning (PEFT)
- LoRA / QLoRA techniques
- Model evaluation

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Hugging Face Datasets
- PEFT
- Accelerate
