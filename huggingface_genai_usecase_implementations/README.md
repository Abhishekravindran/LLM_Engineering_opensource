# HuggingFace GenAI Usecase Implementations

This folder contains hands-on implementations and experiments using Hugging Face tools, models, and libraries for Generative AI use cases.

## Contents

### Notebooks

- **Week_1_Day_1_Colab.ipynb**
  - Introduction to Generative AI workflows and Hugging Face ecosystem.

- **week_3_day_2_pipelines.ipynb**
  - Working with Hugging Face pipelines for different NLP and GenAI tasks.

- **Week_3_Day_3_tokenizers.ipynb**
  - Understanding tokenization, tokenizer workflows, and text preprocessing.

- **Week_3_Day_4_models.ipynb**
  - Exploring Hugging Face models and model loading techniques.

- **Week_3_Day_5_Meeting_Minutes_product.ipynb**
  - Building a GenAI-based product use case for meeting minutes generation.

## Technologies Used

- Python
- Hugging Face Transformers
- Hugging Face Datasets
- Hugging Face Tokenizers
- Large Language Models (LLMs)
- Generative AI workflows
